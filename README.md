# Yasmeen Hasan

Portfolio and calling card for Yasmeen Hasan, web designer and developer.

Live: https://yasmeen-calling-card.vercel.app

Started in [v0](https://v0.app) and connected to GitHub from the v0 project, then rebuilt with the
full portfolio design: a hand-drawn garden of vines, blossoms and butterflies, scroll reveals and
view transitions, all CSS-first.

## Run it

```bash
npm install
npm run dev
```

Next.js 16, React 19, Tailwind CSS v4.
